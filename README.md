# Ddock

MVP프로젝트 영상 요약 콘텐츠 자동화 — 디자이너를 위한 AI 브리핑 서비스. 영상 스크립트를 "안 봐도 손으로 따라할 수 있는" 학습 카드로 바꿔서 보여주는 웹앱입니다.

## 지금 들어있는 것

- **홈 (`/`)** — 영상(코스) 목록
- **상세페이지 (`/videos/[courseId]`)** — 영상 설명, 태그, 학습 카드 5개 요약
- **따라잡기 탭 (`/videos/[courseId]/learn`)** — 시안 B(카드형 넘기기) 기준: STEP을 하나씩 넘기며 액션 → 프롬프트 복사 → ⚠ 주의 → ⓘ 바텀시트를 확인하고, 카드 끝에서 체크포인트를 봐요.

시드 콘텐츠는 프로젝트 문서 `claude/B안_카드구성.md` 원문을 그대로 옮겼어요 (`src/data/course.ts`).
`difficulty`(난이도), `tags`(태그 칩) 값은 문서에 정확한 기준이 없어 임시로 채운 값이라 명세서(v0.6.1) 확정되면 교체해야 합니다.

## 아직 없는 것 (다음 작업)

- 실제 디자인 반영 — 지금은 기본 스타일(Tailwind 뉴트럴 톤)이고, 피그마 시안이 오면 컴포넌트별로 교체할 예정
- 시안 A(아코디언+타임라인) vs 시안 B(카드형 넘기기) 최종 결정 — `claude/작업현황.md` 참고
- 빈 상태 화면 (리뷰 0개일 때)
- 로그인/서버 없이 정적 데이터로만 동작 — 진행 상태는 새로고침하면 초기화됨
- 스크립트 탭, 결과물 공유 탭 (Figma `03 · 스크립트 · 결과물 공유 · 완료` 섹션)

## 개발

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # 프로덕션 빌드 검증
```

## 배포

Vercel에 이 저장소를 연결하면 기본 설정 그대로 배포돼요 (Next.js App Router, 별도 환경변수 없음).

## 폴더 구조

```
src/
  app/                     # 라우트
  components/              # 화면 조각 (PromptBlockView, InfoSheet, WarningBadge 등)
  data/course.ts           # 시드 콘텐츠
  lib/types.ts             # 학습 카드 데이터 모델
```
