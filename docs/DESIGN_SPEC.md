### 4.1 PartCard — 파트 카드 `357:13400` 외

```
크기      343 × 142
테두리    1px #E4E4E7   라운드 12   패딩 16
세로 배치 gap 20
```

**배경은 상태에 따라 달라요.**

| 상태 | 배경 |
|---|---|
| 완료 (`done === total`) | `#F4F4F5` (zinc/100) |
| 진행 중 · 미시작 | `#FFFFFF` (white) |

| 요소 | 값 |
|---|---|
| 상단 행 | `flex` gap 7, 세로 가운데, `padding-right: 8` |
| 썸네일 | 110 × 72, 라운드 2, `object-fit: cover` |
| 파트 배지 | 썸네일 좌상단 안쪽 4px, 칩 `px 4 py 2` 라운드 4, 그라디언트+블러 6, `2xs/medium` `#FDFDFD` |
| 텍스트 열 | `flex:1` gap 2, 높이 56, 세로 가운데 |
| 제목 | `sm/bold` `#18181B`, 최대 2줄 |
| 타임 | `2xs/medium` `#3A3A3E` |

**게이지**

```
트랙   폭 309(= 343 - 패딩 32 - 2)  높이 16  라운드 100  배경 #D4D4D8
채움   높이 16  라운드 100  배경 #F97316   폭 = 309 × (done / total)
라벨   2xs/bold  가운데 정렬  폭 24  좌표 x=142.5  (즉 142.5 ~ 166.5 구간)
```

**라벨 색 규칙** — 오렌지가 라벨까지 왔을 때 흰색으로 뒤집혀요.

| 조건 | 라벨 색 |
|---|---|
| 채움 폭 **≥ 163px** (트랙의 52.75%) | `#FDFDFD` |
| 그 미만 | `#52525B` |

구현은 두 가지 방법이 있어요.

```
방법 A (권장) — 라벨을 두 겹으로 깔고 흰색 겹만 채움 폭으로 clip
  ▸ 오렌지가 라벨에 반쯤 걸쳐도 걸친 만큼만 흰색이라 어떤 값에서도 자연스러워요
  ▸ 163 같은 고정 숫자가 안 들어가서 화면 폭이 바뀌어도 안 깨져요

방법 B (피그마 그대로) — 채움 비율 ≥ 52.75%면 통째로 흰색
  ▸ 코드 한 줄. 대신 딱 그 지점에서 색이 툭 바뀌어요
```

방법 A로 짜두고, 결과 보고 마음에 안 들면 B로 내리는 걸 추천해요.

`0 / 4`일 땐 채움 요소 자체가 없어요 (폭 0이 아니라 렌더 안 함).

**스와이프 → 로그 작성** (`357:13442`) — 카드를 왼쪽으로 밀면 오른쪽에서 카메라 버튼이 나와요.

```
밀기 전   카드 343
민 뒤     카드 343 + 카메라 영역 90 = 453
카메라    박스 90 × 90, 아이콘 24 × 24 (vuesax/linear/camera)
누르면    결과물 작성 화면(355:9467)
```

완료(4/4) 카드만이 아니라 **아무 카드나 밀어서 쓸 수 있어요.** 카드를 다 끝내야만 로그를 남길 수 있는 게 아니라는 뜻이에요.

MVP에서는 뺍니다 — 로그 저장에 서버가 필요해서 로그북과 한 묶음으로 뒤로 미뤄요.

### 4.2 LearningCard — 학습 카드 `355:9781`

  ```
  배경   #F4F4F5      테두리 1px #E4E4E7
  ```

    기본형은 `1`, 프롬프트형은 `2` — 이 카드에 딸린 ⓘ 개수로 보이는데 **확인 필요** (7번)
- 구간 재생 버튼: 박스 44 × 44, 패딩 8, 아이콘 32 × 32 (4.13의 재생/멈춤 컴포넌트)

- 제목 `xl/bold` `#18181B`
- 제목↔불릿 간격 24
- 불릿 리스트: 세로 gap 6
  - 점 6 × 6 오렌지 원(SVG), 텍스트와 gap 6
  - 텍스트 `sm/normal` `#3F3F46`

**프롬프트 블록** (프롬프트형만)

```
라벨행  양끝 정렬 — "복사해서 그대로 쓰세요" 2xs/medium #A1A1AA  +  복사 아이콘 12×12
본문    2xs/semibold #52525B   본문 영역 58px = 14px 행간 × 4줄
```

**긴 프롬프트 규칙** — 프롬프트가 길어도 카드가 늘어나면 안 돼요. 박스 안에서 4줄까지만 보이고 끝에 `…`가 붙습니다.
복사 버튼은 **화면에 보이는 잘린 글이 아니라 원문 전체**를 클립보드에 넣어요.

```css
.prompt-body {
  display: -webkit-box;
  -webkit-line-clamp: 4;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
```

```ts
// 잘린 DOM 텍스트가 아니라 데이터의 원문을 넘겨요
navigator.clipboard.writeText(step.prompt.code)
```

펼치기 동작은 없어요. 전문을 보려면 복사해서 붙여넣으면 됩니다.

## 5. 까다로운 것 5개

**1. 카드 스와이프 스택** — 가이드 탭의 핵심이에요. 앞 카드를 좌우로 밀면 다음 카드가 올라옵니다. 뒤 카드는 0.9배.
→ `framer-motion`의 `drag="x"` + `useMotionValue`로 40줄 정도면 됩니다. 대안 `@use-gesture/react`.

**2. 바텀시트 드래그** — 손가락으로 끌어내려 닫는 동작.
→ `vaul`(shadcn Drawer의 원본)이 이 용도 전용이에요. 직접 짜면 스크롤 잠금·스냅포인트 때문에 시간이 훨씬 더 듭니다.

**3. 이미지 에셋** — 피그마 MCP가 주는 이미지 URL은 7일 뒤 만료돼요. 썸네일·도구 아이콘·재생 아이콘·불릿 점 전부 저장소에 넣어야 합니다.
→ 피그마에서 export → `public/`에 커밋. SVG 아이콘은 인라인 컴포넌트로 빼는 게 관리하기 편해요.

**4. 영상 재생** — 썸네일 가운데 버튼과 카드 우상단 버튼이 같은 영상을 조종해요. 카드 쪽은 그 STEP 구간만 재생하고요.
→ 유튜브 IFrame Player API로 `seekTo(초)` + `playVideo()` / `pauseVideo()`. 두 버튼이 같은 플레이어를 보게 상태를 위로 끌어올려야 해요 (context 하나면 충분).
→ 타임스탬프가 `09:51-12:36` 같은 문자열이라 초로 바꾸는 함수가 필요해요.

**5. 폰트** — Pretendard는 Google Fonts에 없어요.
→ `pretendard` npm 패키지의 woff2 subset을 `next/font/local`로 등록. `variable` 옵션으로 Tailwind `--font-pretendard`에 연결.

3·5번은 코드 짜기 전에 끝내는 게 좋아요. 나머지는 해당 화면 만들 때 같이 붙이면 됩니다.

`src/lib/types.ts`를 피그마 기준으로 고쳐요. 늘어나는 것:

```ts
Course      + youtubeId, viewCount, likeCount, rating, publishedAt
            + channel{name, avatar, url}
            + recommend{badge, title, body}     // 추천 카드
```
